# 🤖 Telegram-бот для возврата товаров

AI-бот на базе OpenAI GPT для автоматизированной обработки заявок на возврат товаров. Ведет естественные диалоги, умно собирает данные и отправляет структурированные заявки операторам.

## 🎯 Что делает

Бот автоматизирует процесс возврата товаров:
- Ведет естественные диалоги с клиентами через GPT
- Извлекает структурированные данные из свободного текста
- Валидирует все входные данные по доменным правилам
- Защищает собранные данные от случайной перезаписи
- Отправляет отформатированные заявки в операторский чат

## 🛠️ Технологии

- **Python 3.12+** - Основной язык
- **aiogram 3.13** - Фреймворк для Telegram ботов
- **OpenAI API** - GPT-4 для обработки естественного языка
- **httpx** - Асинхронный HTTP-клиент с поддержкой proxy
- **pydantic** - Валидация данных и управление настройками
- **Docker** - Контейнеризация для деплоя

## ✨ Ключевые возможности

### 🧠 Умный сбор данных
- Извлекает информацию из естественного языка
- Обрабатывает несколько данных в одном сообщении
- Валидирует доменные поля (номера заказов, названия товаров)
- Мягко дозапрашивает необязательные поля без навязчивости

### 🛡️ Защита данных
- **State machine** с явными флагами подтверждения полей
- **Нет перезаписи** уже подтвержденных обязательных полей
- **Валидация** предотвращает принятие явно невалидных данных
- **Rate limiting** защищает от спама (проверка ДО вызова LLM)

### 🌐 Сетевые возможности
- **Поддержка proxy** для OpenAI и Telegram API
- Работает в регионах, где сервисы заблокированы
- URL-encoding для спецсимволов в credentials

### 📊 Собираемые данные

**Обязательные:**
- Имя клиента
- Контакт (телефон/email/Telegram)
- Номер заказа (валидируемый формат)
- Название товара
- Причина возврата
- Состояние товара

**Необязательные (мягкий дозапрос):**
- Дата покупки
- Способ возврата денег

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Клонировать репозиторий
git clone https://github.com/eth1r/telegram-return-bot.git
cd telegram-return-bot

# Установить зависимости
pip install -r requirements.txt

# Настроить окружение
cp .env.example .env
# Отредактировать .env с вашими credentials:
# - TELEGRAM_BOT_TOKEN (от @BotFather)
# - OPERATOR_CHAT_ID (команда /chatid)
# - OPENAI_API_KEY

# Запустить бота
python main.py
```

### Деплой через Docker

```bash
# Собрать и запустить
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановить
docker-compose down
```

## ⚙️ Конфигурация

### Обязательные переменные окружения

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_бота
OPERATOR_CHAT_ID=ваш_chat_id
OPENAI_API_KEY=ваш_ключ_openai
```

### Опциональные настройки

```bash
# OpenAI
OPENAI_MODEL=gpt-4.1-mini
OPENAI_BASE_URL=https://api.openai.com/v1

# Proxy (если нужен)
HTTP_PROXY=http://user:pass@host:port
HTTPS_PROXY=http://user:pass@host:port

# Rate Limiting
RATE_LIMIT_MESSAGES=20
RATE_LIMIT_WINDOW_SECONDS=3600

# Логирование
LOG_LEVEL=INFO
```
