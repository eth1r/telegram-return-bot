## 1. ЧТО РЕАЛИЗОВАНО

### ✅ Автоопределение item_condition по маркерам

Создан модуль `services/assistant/condition_detector.py` с умной логикой определения состояния товара.

**Маркеры для "повреждён":**
- скол, трещина, разбит, разбилась, сломан, сломался
- повреждён, повреждена, дефект, брак
- не работает, экран не работает, не включается
- пришёл с браком, пришёл повреждённым
- помят, царапина, поцарапан
- битый, треснул, со сколом, с трещиной
- неисправен, сбой, глюк, отвалил

**Маркеры для "вскрыт":**
- вскрыл, вскрыта, открыл упаковку
- распаковал, упаковка вскрыта

**Маркеры для "использовался":**
- пользовался, использовал, носил
- включал, пробовал, применял

**Маркеры для "не использовался":**
- не открывал, не вскрывал, не пользовался
- в упаковке, новый, не распакован
- запечатан, в пленке

**Приоритет определения:**
1. "повреждён" (самый важный)
2. "не использовался" (явный отказ)
3. "использовался"
4. "вскрыт"

### ✅ Обезличивание демо-режима

В демо-режиме (`is_demo=true`) бот НЕ собирает:
- `name` (имя клиента)
- `contact` (телефон/email/Telegram)

**Обязательные поля в демо-режиме:**
- order_number
- product_name
- return_reason
- item_condition

**Обязательные поля в Telegram-режиме:**
- name
- contact
- order_number
- product_name
- return_reason
- item_condition

### ✅ Улучшенный UX

**Было:**
```

Бот: "Понял. В каком состоянии товар: не использовался, вскрыт, использовался или повреждён?"
```


Бот автоматически определил `item_condition = "повреждён"` и пропустил вопрос.

## 3. КАК ТЕПЕРЬ РАБОТАЕТ АВТООПРЕДЕЛЕНИЕ

### Логика в workflow.py:

```python
# Автоопределение состояния товара из сообщения пользователя
detected_condition = detect_item_condition(message_text)
if detected_condition and not session.ticket.item_condition:
    logger.info(
        "Auto-detected item_condition='%s' for user_id=%s from message",
        detected_condition,
        session.user_id
    )

# Применяем автоопределенное состояние
if detected_condition and not session.ticket.item_condition:
    session.ticket.item_condition = detected_condition
```

## 8. ПРИМЕРЫ РАБОТЫ АВТООПРЕДЕЛЕНИЯ

### Повреждён:
- "тарелка пришла со сколом" → `повреждён`
- "товар сломан" → `повреждён`
- "экран не работает" → `повреждён`
- "пришёл с браком" → `повреждён`
- "с трещиной" → `повреждён`

### Вскрыт:
- "вскрыл упаковку" → `вскрыт`
- "распаковал" → `вскрыт`

### Использовался:
- "пользовался неделю" → `использовался`
- "носил пару раз" → `использовался`

### Не использовался:
- "не открывал" → `не использовался`
- "в упаковке" → `не использовался`
- "новый" → `не использовался`

### Приоритет:
- "пришёл повреждённым, не использовал" → `повреждён` (приоритет)

### Не определено:
- "не подошёл размер" → `None` (бот спросит)
- "передумал" → `None` (бот спросит)
